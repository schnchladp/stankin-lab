# Лабораторная работа № 1 — сервис доставки

## О работе

Учебный проект на Python, моделирующий предметную область сервиса доставки (вариант 26) с использованием объектно-ориентированного программирования. Программа демонстрирует классы и связи между сущностями, операции управления данными, обработку исключительных ситуаций и сериализацию в JSON и XML.

## Основные возможности

- представление сущностей предметной области с помощью классов (клиент, курьер, посылка, заказ, доставка, тариф, оплата, отзыв);
- операции добавления, поиска, изменения и удаления записей (CRUD);
- назначение свободного курьера, допустимые переходы статусов, проверка связей при удалении;
- расчёт стоимости по тарифу (расстояние, вес, экспресс-доставка, хрупкость);
- проверка входных данных и обработка ошибок с помощью собственных исключений;
- сохранение и загрузка данных в форматах JSON и XML;
- консольное меню для работы с системой;
- демонстрационный сценарий, включая проверку ошибочных ситуаций;

## Запуск

Требуется Python 3.10 или новее, дополнительные библиотеки не нужны.

Перейдите в каталог `lab1` и выполните:

```bash
python main.py
```

Для запуска демонстрационного сценария:

```bash
python demo.py
```

## Проверка вводимых данных

- имя — только буквы, пробелы и дефис (`Маша-Саша Ли`);
- телефон — мобильный номер `+79XXXXXXXXX` или `89XXXXXXXXX` (пробелы, дефисы и скобки допускаются), хранится в виде `+79XXXXXXXXX`, уникален;
- госномер — только у автомобиля, формат `А123ВС77` (самокат и велосипед номера не имеют);
- вес, расстояние, сумма — больше нуля; оценка — от 1 до 5.

Любая ошибка приводит к сообщению в меню, программа не завершается.

## Форматы данных

Программа поддерживает сохранение и загрузку данных в форматах JSON и XML (пункты 7 и 8 главного меню; загрузка заменяет текущие данные в программе и просит подтверждение). Данные одной предметной области представляются в двух форматах, что демонстрирует сериализацию и десериализацию.
