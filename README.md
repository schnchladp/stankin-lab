Репозиторий объединяет учебные лабораторные работы по программированию на Python в рамках дисциплины «Прикладное программирование».

## Как начать работу

1. Откройте README нужной лабораторной работы по ссылке в таблице выше.
2. Ознакомьтесь с описанием проекта и его структурой.
3. Проверьте требования к версии Python и зависимостям.
4. Следуйте инструкциям по запуску программы.
5. В папке `docs/` соответствующей лабораторной находятся отчет и дополнительные материалы.
